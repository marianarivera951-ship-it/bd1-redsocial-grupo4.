## Descripción del Proyecto
Este repositorio contiene el diseño del modelo conceptual (Diagrama Entidad-Relación - MER) para la plataforma **Red Social Pascualina**, desarrollada como parte de la Tarea 1 del curso de Bases de Datos 1.

### Contenido del Repositorio
- `tarea1/informe/`: Contiene el informe técnico en formato PDF con la identificación de entidades, atributos, relaciones, cardinalidades y el diagrama MER.
- `tarea1/video/`: Contiene el archivo con el enlace de la sustentación en video.
